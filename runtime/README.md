# Bundled runtime

`notepad-plus-plus-headless/` contains the complete portable Notepad++ 8.5.7
x64 runtime used by the bridge. It is selected automatically unless `NPP_EXE`
explicitly overrides it.

The bridge source is MIT-licensed, but the bundled runtime is not. See
[`notepad-plus-plus-headless/SOURCE.md`](notepad-plus-plus-headless/SOURCE.md)
and the licenses included with the runtime.
